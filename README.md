# BarcodeCV

Структура репозитория

i_video_frames - папки с примерами кадров, полученные из i-го видео

В папках _results содержаться результаты обработки при для каждого видео при помощи соответствующей библиотеки

Для использования barcode_tests.py необходимо устаносить библиотеки при помощи:

```pip install pyzbar qreader zxing-cpp opencv-python numpy```
